# v1.3.1

本版本是依赖维护与兼容性验证版本：在保持公众号 HTML 渲染行为的前提下升级渲染、构建、测试和 Obsidian 类型依赖，并清除 npm audit 报告的问题。本文件是本次 GitHub Release 的完整发布正文。

## 主要变化

- 升级 `markdown-it` 15、`juice` 11.1.1、`lucide-static` 1.32、`linkedom` 0.18、`esbuild` 0.28、Rollup 4.62、TypeScript 5.9、TypeScript ESLint 8.67、Vitest 4.1 和 Obsidian API 类型 1.13.1。
- 移除项目未使用且已弃用的 `rollup-plugin-terser`，消除其带来的 `serialize-javascript` 高危审计问题。
- 通过 lockfile overrides 使用 `encoding-sniffer` 1.0.2 和 `@xmldom/xmldom` 0.9.11，消除安装时的弃用警告，同时保留 Juice/MathJax 的兼容版本。
- 适配 Markdown-it 15 的类型导出和新版 Obsidian lint 规则；插件最低 Obsidian 版本明确为 0.16.2。
- 真实《样式测试 - 全元素覆盖.md》经过升级前后渲染对比：公式、Callout、表格、代码、图片和诊断结果保持一致；新版图标路径和 CSS 空白格式属于依赖本身的非语义更新。

## 验证

- `npm audit --audit-level=low`：0 vulnerabilities
- `npm test`：22 个测试文件、208 个测试通过
- `npm run lint`：0 error
- `npm run build`：通过

## 安装

下载并解压 [`obsidian-wechat-publish-1.3.1.zip`](https://github.com/ARCJ137442/obsidian-wechat-publish/releases/download/v1.3.1/obsidian-wechat-publish-1.3.1.zip) 到：

`.obsidian/plugins/obsidian-wechat-publish/`

然后在 Obsidian 的「社区插件」中启用插件。插件仅支持桌面端，最低 Obsidian 版本为 0.16.2。

## 边界

- 不接入微信公众号 API；发布动作仍由用户在公众号后台粘贴 HTML 后完成。
- Copy 模式不嵌入 Base64 图片；本地图片需要在公众号后台手动处理。
