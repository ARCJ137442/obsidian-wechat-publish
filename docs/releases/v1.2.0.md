# v1.2.0

这是本仓库首个正式 GitHub Release，提供可直接安装的 Obsidian 插件压缩包。

## 主要变化

- Preview 与 Copy 现在共用同一套 Markdown → HTML 渲染核心，Callout、Wikilink、LaTeX 和高亮的生产路径由真实测试覆盖。
- Preview 保留本地图片预览；Copy 继续使用 `【图片：...】` 占位符，避免 Base64 图片导致公众号编辑器卡死。
- Preview 与 Copy 共用 MathJax SVG 公式渲染，支持中文公式、矩阵和较复杂的行间公式。
- 使用正式 YAML 解析 frontmatter，统一支持 BOM、CRLF、多行字段、数组和嵌套值；标题、日期和作者回退规则在 Preview 中统一处理。
- 完整的样式测试笔记已纳入测试 fixture，覆盖内置 Callout、自定义 Callout、公式、图片、表格、代码和组合场景。
- 插件明确声明为桌面端插件，并提供 GitHub Release 安装包；版本、构建、lint 和测试已接入 GitHub Actions。

## 安装

下载并解压 [`obsidian-wechat-publish-1.2.0.zip`](https://github.com/ARCJ137442/obsidian-wechat-publish/releases/download/v1.2.0/obsidian-wechat-publish-1.2.0.zip) 到：

`.obsidian/plugins/obsidian-wechat-publish/`

然后在 Obsidian 的「社区插件」中启用插件。

## 边界

- 不接入微信公众号 API；发布动作仍由用户在公众号后台粘贴 HTML 后完成。
- Copy 模式不嵌入 Base64 图片；本地图片需要在公众号后台手动处理。
