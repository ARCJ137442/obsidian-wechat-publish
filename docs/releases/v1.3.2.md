# v1.3.2

本版本为运行时边界与状态安全修复版本，保持既有 Markdown 转微信公众号 HTML 的输出行为不变。

## 主要变化

- 将桌面端 Node.js/Electron 能力集中到显式运行时适配层，降低浏览器/移动端环境误调用风险。
- Callout Manager 主题数据在插件加载、卸载和失败路径中正确重置，避免自定义主题状态泄漏到下一次加载。
- 图片二进制转 Base64 使用统一转换入口，避免逐字节字符串拼接带来的性能和边界问题。
- 补充桌面运行时适配器和 Callout 状态重置测试。

## 验证

- `npm test`：24 个测试文件、213 个测试通过
- `npm run build`：通过
- `npm run lint`：0 errors；保留 6 个既有 warning
- 生产依赖审计：0 vulnerabilities
- Obsidian CLI：`life-series` 插件重载成功，错误缓冲为空

## 安装

下载并解压 [`obsidian-wechat-publish-1.3.2.zip`](https://github.com/ARCJ137442/obsidian-wechat-publish/releases/download/v1.3.2/obsidian-wechat-publish-1.3.2.zip) 到：

`.obsidian/plugins/obsidian-wechat-publish/`

然后在 Obsidian 的「社区插件」中启用插件。插件仅支持桌面端，最低 Obsidian 版本为 0.16.2。
