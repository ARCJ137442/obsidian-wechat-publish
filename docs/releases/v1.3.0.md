# v1.3.0

本版本集中修复 LaTeX 定界符边界，并完成路线图中已排定的预览、复制、主题和命令入口迭代。GitHub Release 会由 CI 自动生成自上一发行版以来的完整提交记录。

## 主要变化

- 修复 CRLF fenced code、代码块内行内三反引号，以及代码内容中的美元符号被误解析或恢复损坏的问题。
- 对齐 Obsidian 的行内美元定界符行为：成对纯数字公式可渲染，未闭合金额保持文本，歧义边界不强行猜测。
- 单美元行内公式限制在同一行；`$$...$$` 行间公式仍支持跨行，包括多行公式和连续公式场景。
- 增加上述 LaTeX 边界、金额、数字公式、代码块和跨行公式的真实渲染管线回归测试。
- 保留此前版本的 CSS 分层、预览服务器续期与错误提示、非阻塞复制摘要、当前笔记/选区/文件菜单入口等能力。

## 安装

下载并解压 [`obsidian-wechat-publish-1.3.0.zip`](https://github.com/ARCJ137442/obsidian-wechat-publish/releases/download/v1.3.0/obsidian-wechat-publish-1.3.0.zip) 到：

`.obsidian/plugins/obsidian-wechat-publish/`

然后在 Obsidian 的「社区插件」中启用插件。插件仅支持桌面端。

## 边界

- 不接入微信公众号 API；发布动作仍由用户在公众号后台粘贴 HTML 后完成。
- Copy 模式不嵌入 Base64 图片；本地图片需要在公众号后台手动处理。

## 自动发布记录

GitHub Actions 在推送 `v1.3.0` tag 后会自动运行 build、lint 和 test，生成从 `v1.2.0` 到 `v1.3.0` 的提交记录，并上传可直接安装的插件 zip。
