# v1.4.0

本版本解除移动端加载限制，并把移动端复制能力扩展为可直接使用的跨平台复制出口。

## 主要变化

- `manifest.json` 的 `isDesktopOnly` 改为 `false`；移动端启动时显示非阻断提示，说明复制可用、预览仍仅支持桌面端。
- 复制到微信默认不再弹出确认模态框，直接执行复制；桌面端优先使用 Electron 系统剪贴板，其他环境使用 Web Clipboard API。移动端直写若被 WebView 拒绝，会自动进入统计模态框的按钮重试路径。
- 新增设置 `Preview before copying (复制前弹窗预览)`，默认关闭；开启后“复制到微信”和“复制 HTML 纯文本”共用统计模态框，展示正文总字数、复制内容类型、HTML 字符数和 UTF-8 大小。
- “复制 HTML 纯文本”支持跨平台将内联 HTML 源码写入纯文本剪贴板，便于发送或保存为 `.html` 文件。

## 移动端验收边界

- Android 真机：移动端加载、启动提示、浏览器 API 复制和 HTML 纯文本导出通过。
- Android Edge 的微信公众号输入框实测只能接收为 HTML 源文本，未将其宣称为渲染后的富文本兼容；这是目标输入框的系统/WebView 能力边界。
- HTML 纯文本可以发送和保存为独立文件。
- 浏览器预览仍仅支持桌面端；不接入微信公众号官方 API，不自动上传图片。
